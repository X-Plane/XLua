<h1>XPLM Sound API</h1>
---

This provides a minimal interface into the FMOD audio system. On the simplest level, you can
request that X-Plane plays an in-memory audio buffer. This will work without linking to FMOD
yourself.
If you want to do anything more, such as modifying the sound, or loading banks and triggering your
own events, you can get a pointer to the FMOD Studio instance.
